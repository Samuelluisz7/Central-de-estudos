# Central de Estudos

Aplicação web estática para organizar a preparação para o ENEM 2026.

## Recursos
- Painel com sessões, tempo acumulado e prioridades.
- Mapa inicial de 11 matérias e tópicos.
- Diagnóstico baseado nos resultados já registrados.
- Plano semanal de referência.
- Registro de sessões com conteúdo, tempo, acertos e observações.
- Revisões espaçadas em D+1, D+7 e D+14.
- Armazenamento local no navegador (localStorage).

## Executar
Abra `index.html` em um navegador moderno. Não há dependências externas nem processo de build.

## Dados
Os registros de sessões e revisões ficam no armazenamento local do navegador/dispositivo. Não são sincronizados entre dispositivos e podem ser perdidos se os dados do navegador forem apagados.
